# Список крупных задач по системам

## АБС
- Реализовать модуль хранения и расчёта ставок в Oracle (для бэк-офиса депозитов и кредитов)
- Разработать API/процедуру для передачи ставок в систему кол-центра банка
- Разработать планировщик выгрузки ставок в файл (CSV/XLS) для партнёрского кол-центра
- Настроить безопасную передачу файлов партнёру (SFTP или e-mail с шифрованием)

## Система кол-центра банка
- Добавить модуль отображения ставок в UI операторов
- Реализовать интеграцию с АБС для получения ставок
- Обеспечить кэширование для снижения нагрузки на АБС

## Система партнёрского кол-центра
- Настроить приём и обновление файлов ставок
- Обеспечить удобное отображение ставок для операторов

## Инфраструктура / безопасность
- Настроить SFTP-сервер или защищённую почтовую передачу
- Реализовать шифрование PGP для файлов
